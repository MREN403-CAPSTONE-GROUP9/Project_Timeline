# Project Timeline & Management

**MREN 403 | Autonomous Snow-Clearing Robot for Kingston City Sidewalks**

This repository provides an overview of the project schedule and key milestones for the development of our autonomous snow-clearing robot. The timeline covers both the Fall and Winter semesters of the 2026–2027 academic year, from initial requirements and concept development through detailed design, prototyping, testing, and final project delivery.

## Project Timeline

The project is organized into several major phases:

1. **Requirements & Concept Development:** Establish project requirements, investigate potential solutions, and develop preliminary concepts.
2. **Preliminary & Detailed Design:** Develop mechanical, electrical, and software designs.
3. **System Integration:** Assemble and integrate the various subsystems into a functional prototype.
4. **Testing & Validation:** Evaluate robot performance and refine the design.
5. **Final Deliverables:** Complete project documentation, final report, and presentation.
